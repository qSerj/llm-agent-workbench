# Пример преобразования звука

Это минимальный сквозной пример актуальной лаборатории без языковой модели.
Сценарий сам создаёт двухсекундный стереофонический WAV 48 кГц и запускает два
способа решения задачи «получить монофонический FLAC 16 кГц той же длительности»:

- `ffmpeg-correct` выполняет требования;
- `ffmpeg-truncated` намеренно обрезает звук и не меняет частоту и число каналов.

`ffprobe` проверяет кодек, частоту, число каналов и длительность. Для каждого
способа создаётся отдельный каталог с результатом, журналом, доказательством
`ffprobe` и `execution-envelope.json`.

```bash
python3 examples/audio_conversion/run.py --output /tmp/audio-experiment
```

Здесь задача, пример, способы решения и правило оценки пока заданы прямо в
`run.py`. Это демонстрация границ и движения данных, а не предлагаемый общий
формат описания будущих задач.
