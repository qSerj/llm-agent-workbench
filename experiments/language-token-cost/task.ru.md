# Исправление свёртки диапазонов

В `ranges.py` находится функция `collapse_ranges(values)`. Исправь её так,
чтобы она выполняла следующий договор целиком.

1. Функция принимает любой итерируемый объект целых чисел и возвращает строку.
2. Числа сортируются по возрастанию, повторы удаляются. Входной объект не изменяется.
3. Три и более последовательных числа записываются как `start-end`.
4. Одно или два последовательных числа записываются по отдельности.
5. Фрагменты разделяются запятыми без пробелов.
6. Отрицательные границы сохраняют знак: `[-3, -2, -1]` превращается в `-3--1`.
7. Пустой вход даёт пустую строку.
8. `bool` и любое значение, не являющееся `int`, поднимает `TypeError`.

Примеры:

```python
collapse_ranges([1, 2, 3, 5, 7, 8]) == "1-3,5,7,8"
collapse_ranges(iter([4, 3, 3, 2])) == "2-4"
```

Внешних зависимостей не добавляй. Проверяй поведение командами Python. Правь
только `ranges.py` и не создавай другие файлы. Итогом должна быть работающая
реализация, а не описание решения.
