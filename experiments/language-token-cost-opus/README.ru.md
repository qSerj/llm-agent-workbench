# Языковой опыт: Claude Opus 5

Последний круг опыта `language-token-cost`: та же фикстура, эквивалентные
русская и английская постановки, скрытые проверки и пять парных повторов.

Запуск:

```bash
.research-env/bin/python3 tools/run_chain.py \
  experiments/language-token-cost-opus/experiment.yaml
```

Парная сводка:

```bash
python3 experiments/language-token-cost/analyze.py RUN_DIRECTORY \
  --ru opus-ru --en opus-en
```

Сравнение также входит в общую страницу оболочки `/series` вместе с Mimo,
Terra и Sonnet.

## Прогон 2026-08-31

Все десять исполнений получили `suite: PASS`, 10 из 10 проверок. Полная серия
стоила $1,685884.

| метрика | EN, среднее | RU, среднее | отношение средних RU/EN | медиана пар RU/EN |

| стоимость, $ | 0,170171 | 0,167006 | 0,981 | 0,982 |

Opus не показала перерасхода русского языка: русский вариант в среднем
использовал на 4,6% меньше общих токенов и стоил на 1,9% дешевле. Парные
медианы практически равны единице. При одинаковом качестве направление эффекта
оказалось противоположным Mimo и Sonnet.
