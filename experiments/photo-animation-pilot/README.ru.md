# Пилот оживления семейных фотографий

Цель — дешёво проверить две отдельные операции: оживление одной фотографии и
генеративный переход между выбранным кадром одного оживления и следующим
возрастом. Финальный монтаж остаётся человеческой работой.

Планы `round-*.yaml` исполняются отдельным бюджетным инструментом:

```bash
.research-env/bin/python3 tools/run_video_pilot.py \
  experiments/photo-animation-pilot/round-1.yaml --dry-run
```

Без `--dry-run` инструмент получает живой каталог моделей, проверяет размер и
длительность, резервирует цену с коэффициентом 1,5 и прекращает запуск до
платного запроса, если план не помещается в лимит. Фактическая стоимость
записывается из `usage` завершённой задачи; неизвестная стоимость не становится
нулём.

Первый прогон 2026-09-11 дал три пригодных четырёхсекундных оживления на
`bytedance/seedance-1-5-pro` и переход «комната → парк» через листовой проход.
Стоимость четырёх успешных генераций — $0.191476. Запрос к
`bytedance/seedance-2.0-mini` был отклонён до генерации политикой приватности для
фотографии реального человека.

Последующие прогоны подтвердили более подходящую структуру перехода между
возрастами: спокойное оживление, мотивированный выход персонажа, монтаж по
направлению движения, проход камеры через элемент следующей фотографии и
спокойное раскрытие нового возраста. В проверке «кухня → комната» девочка
оставляет ложку, уходит вправо, после чего камера проходит мимо дверного проёма
второй фотографии и открывает девочку на стуле. Отдельный следующий клип
сохраняет почти статичную позу в течение четырёх секунд.

Три дополнительные генерации стоили $0.143607, все семь успешных генераций —
$0.335083. Исходные фотографии, производные кадры и видео находятся только
локально и исключены из Git: планы содержат пути к ним, но не сами материалы.
