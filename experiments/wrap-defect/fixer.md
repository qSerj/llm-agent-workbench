# Исправление по замечаниям

В рабочем пространстве находятся договор `README.md`, текущий `wrap.py` и
замечания проверяющего `review-findings.json`.

Проверь каждое замечание запуском кода. Исправь только `wrap.py`: устрани
подтверждённые нарушения договора, не ломая уже работающие пункты. Ошибочное
замечание не применяй. Не изменяй `README.md` и `review-findings.json`.

Перед завершением прогони поведение по всем пунктам договора ещё раз.
