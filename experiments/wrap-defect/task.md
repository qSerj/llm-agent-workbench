# Отчёт о дефекте: перенос ломает строку раньше времени

В `wrap.py` живёт `wrap_text(text, width)`. Её договор целиком записан в
`README.md` рядом.

Наблюдение: при `width = 7` вызов `wrap_text("раз два", 7)` возвращает две
строки, хотя `"раз два"` — это ровно семь символов и помещается целиком.

Почини `wrap.py` так, чтобы функция вела себя по договору из `README.md`.
Проверяй поведение сам: запускай `python3 -c "import wrap; ..."` и сверяй
результат с каждым пунктом договора, а не только с тем, о котором сообщено.
Внешних зависимостей не добавляй. Правь только `wrap.py`; `README.md` — это
договор, и он не меняется.
