# Проверка починки по договору

В рабочем пространстве лежат договор `README.md` и починенный `wrap.py`.

Проверь `wrap.py` по каждому пункту договора отдельно. Запускай код, а не
рассуждай о нём: `python3 -c "import wrap; print(repr(wrap.wrap_text(...)))"`.
Отчёт о дефекте назвал один симптом; договор шире, и нарушение любого его пункта
— замечание.

Не изменяй `wrap.py`. Создай только `review-findings.json`:

```json
{
  "verdict": "PASS или FAIL",
  "findings": [
    {
      "id": "короткий-стабильный-идентификатор",
      "rule": "номер пункта договора",
      "observed": "что именно вернул вызов, с самим вызовом",
      "expected": "что требует договор",
      "suggested_fix": "конкретное исправление"
    }
  ]
}
```

`PASS` допустим только при пустом списке замечаний.
