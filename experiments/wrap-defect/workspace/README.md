# wrap

Одна функция: `wrap_text(text, width)` из `wrap.py`. Раскладывает текст по
строкам не длиннее `width` символов и возвращает результат одной строкой,
разделённой `\n`.

## Договор

1. **Ширина соблюдается.** Ни одна строка результата не длиннее `width`.
2. **Строка ровно в ширину допустима.** Слово, которое помещается вплотную,
   остаётся на текущей строке; переносить его на следующую нельзя.
3. **Перенос только по пробелам.** Слово внутри не разрывается. Слово длиннее
   `width` занимает свою строку целиком и выходит за ширину — это единственное
   исключение из пункта 1.
4. **Абзацы сохраняются.** Абзацы разделены пустой строкой (`\n\n`) во входе, и
   ровно так же разделены в выходе. Число абзацев не меняется.
5. **Пробелы приводятся в порядок.** Подряд идущие пробелы и переводы строк
   внутри абзаца схлопываются в один пробел; ни одна строка не начинается и не
   заканчивается пробелом.
6. **Слова не теряются и не появляются.** Последовательность слов на выходе та
   же, что на входе.
7. **Ширина меньше единицы — ошибка.** `wrap_text(text, 0)` и любая меньшая
   ширина поднимают `ValueError`. Молча подставлять что-то своё нельзя.
8. **Пустой текст даёт пустую строку.**

## Как запускать

```
python3 -c "import wrap; print(wrap.wrap_text('раз два три', 8))"
```

Внешних зависимостей нет и быть не должно.
