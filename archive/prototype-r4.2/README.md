# Архив прототипа r4.2

Здесь сохранены прежний OpenCode/.NET-стенд, синтетический C#-репозиторий,
задания, оценщик, настройки провайдеров и построенный на них первый опыт цепочки
«исполнитель → проверяющий → исправляющий».

Это воспроизводимая история исследования, а не часть актуальной архитектуры.
Файлы намеренно перемещены вместе, поэтому старые команды следует выполнять из
этого каталога:

```bash
python3 run_agent.py --version
python3 -m unittest discover -s tests -v
dotnet build fixture/InterleaverBench.sln -m:1
```

Старые отчёты находятся в `docs/research/`, а артефакты первого опыта — в
`experiments/solver_reviewer_fixer/`. Их выводы учтены в нынешней карточке
исполнения, но сам C#-пример больше не определяет развитие лаборатории.
Переходники к ранней версии карточки сохранены как исходный материал и отдельно
не поддерживаются; точное состояние целиком доступно также по тегу
`prototype-r4.2` и в истории Git.
