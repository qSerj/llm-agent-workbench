# LLM Agent Workbench

[English version](README.md)

Исследовательская лаборатория для сравнения полных способов решения задач по
качеству, доказательствам, времени, деньгам и вычислительным ресурсам. Способом
решения может быть обычная программа, одна модель, агент, цепочка агентов,
локально-облачная система или процесс с участием человека.

Проект не создаёт собственную базу экспериментов и просмотрщик трассировок.
MLflow используется для хранения и сравнения экспериментов, OpenTelemetry — для
передачи трассировки. Небольшая принадлежащая проекту карточка исполнения
связывает задачу, пример, способ решения, артефакты, этапы, измерения и оценки.

## Что работает сейчас

- проверка карточки исполнения v1 по JSON Schema;
- контроль целостности файлов и каталогов по SHA-256;
- текстовые и бинарные входные и выходные артефакты;
- независимые программные, модельные и ручные оценки с `PASS`/`FAIL`;
- описание многоэтапного способа решения и затрат каждого этапа;
- перенос измерений и артефактов в MLflow;
- передача исполнения и этапов через OpenTelemetry OTLP;
- воспроизводимый пример преобразования звука обычной программой `ffmpeg`.

## Структура

```text
schemas/       формат карточки исполнения
workbench/     проверка карточек и артефактов, интеграции
tools/         команды переноса в MLflow и OpenTelemetry
examples/      воспроизводимые предметно-независимые примеры
tests/         автономные проверки актуального ядра
docs/          решения, состояние и словарь
archive/       завершённый исторический C#-стенд и ранние исследования
```

## Быстрая проверка

```bash
python3 -m pip install -r requirements-envelope.txt
python3 -m unittest discover -s tests -v
python3 -m py_compile workbench/*.py tools/*.py examples/audio_conversion/run.py
```

Если установлены `ffmpeg` и `ffprobe`, можно получить два исполнения звуковой
задачи — правильное и намеренно дефектное:

```bash
python3 examples/audio_conversion/run.py --output /tmp/audio-experiment
```

Полученные `execution-envelope.json` можно проверить и перенести в MLflow или
OpenTelemetry по [руководству](docs/envelope-v1.md).
