# Словарь проекта

Этот словарь фиксирует русские термины, используемые в обсуждениях и
документации. Английский оригинал приводится для узнавания полей, документации
сторонних программ и профессиональной литературы.

| Русский термин | Английский термин | Значение в проекте |
| --- | --- | --- |
| исследовательская лаборатория | workbench | Весь проект и способ проведения сравнимых экспериментов. |
| карточка исполнения | execution envelope | JSON-документ об одном исполнении: задача, входы, способ решения, результаты, измерения, оценки и ссылки. |
| исполнение | execution, run | Одна фактическая попытка выполнить задачу. |
| способ решения | candidate | Версионированная программа, модель или цепочка, выполняющая задачу. |
| пример задачи | case | Конкретный набор входных данных, на котором проверяется способ решения. |
| этап | stage | Отдельная часть цепочки: исполнитель, проверяющий или исправляющий. |
| цепочка обработки | pipeline, workflow | Несколько связанных этапов решения задачи. |
| исполнитель | solver | Создаёт первоначальный результат. |
| проверяющий | reviewer, verifier | Ищет ошибки и подтверждает утверждения по источникам. |
| исправляющий | fixer | Исправляет первоначальный результат по замечаниям. |
| оценка | evaluation | Проверка качества исполнения, результата, утверждения или хода работы. |
| правило оценки | evaluation policy, rubric | Версионированные критерии и правила вынесения оценки. |
| итог оценки | verdict | `PASS`, `FAIL` или `UNDETERMINED`. |
| скрытый набор проверок | hidden check suite | Заранее известный правильный результат, выраженный набором проверок, которого нет в рабочем пространстве исполнителя: он накладывается оценщиком после прогона. |
| артефакт | artifact | Входной или выходной файл, каталог, журнал либо иные данные исполнения. |
| журнал | log | Необработанная запись событий или вывода программы. |
| трассировка | trace | Связанная последовательность операций одного исполнения. |
| контрольная сумма | content hash, digest | Отпечаток содержимого, используемый для обнаружения изменений. |
| внешняя связь | correlation | Идентификатор той же записи в MLflow, OpenTelemetry или другой системе. |
| наблюдение | observation | Измеренное значение с единицей и способом измерения. |
| происхождение | provenance | Сведения о том, как и из каких источников получен результат. |

Слово «эталон» в репозитории занято дважды: им называют и скрытый набор
проверок, и эталонные числа прогона 2026-08-13
(`experiments/solver-reviewer-fixer/experiment.yaml`, `docs/CURRENT_STATE.md`).
Там, где различие существенно, пишется полностью: «скрытый набор проверок» или
«эталонные числа».

Имена программ, файлов, полей JSON и конструкций программирования не
переводятся. При первом употреблении нового существенного термина сначала
используется русское выражение, а английский оригинал при необходимости
указывается в скобках.
