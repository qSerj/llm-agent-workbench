# Спецификация примера задачи

Статус: черновик; граница видимости согласована.

## Назначение

Пример задачи связывает общую задачу с конкретными входными данными. Всё,
указанное непосредственно в `case.yaml`, разрешено передать исполнителю.

```yaml
schema_version: "0.1"
id: short-stereo-recording
version: "1"
task: audio-to-mono-flac@1

inputs:
  source_audio:
    path: source.wav

metadata:
  description: Двухсекундная синтетическая стереозапись
  tags: [short, synthetic]
```

Ключи в `inputs` должны соответствовать логическим входам задачи. Пути относятся
к каталогу примера; контрольные суммы и размеры лаборатория вычисляет при
подготовке исполнения, а не требует от человека вводить вручную.

## Граница видимости

Известный правильный ответ, специально внесённые ошибки и другие подсказки для
проверки не должны находиться в доступном исполнителю `case.yaml`.

Предлагаемая раскладка:

```text
cases/short-stereo-recording/
├── case.yaml
├── source.wav
└── evaluation/
    └── expected.yaml
```

Лаборатория передаёт исполнителю `case.yaml` и объявленные входы, а содержимое
`evaluation/` — только соответствующему оценщику. Это правило должно
обеспечиваться программой, а не одной договорённостью в документации.

## Согласованная модель входов

Задача объявляет логические входы и их ограничения. Пример привязывает к ним
конкретные данные до исполнения. Подготовка исполнения вычисляет размеры,
контрольные суммы и фактические типы; человек не вводит их вручную.

Для версии 0.1 различаются:

- **артефакт** — один файл или каталог, структура которого имеет значение;
- **набор артефактов** — массив самостоятельных файлов;
- **значение** — небольшой скаляр или структура параметров.

```yaml
inputs:
  source_audio:
    path: source.wav

  source_documents:
    - path: documents/report.pdf
    - path: documents/appendix.docx

  options:
    language: ru
    preserve_metadata: true
```

Каталог не равен массиву файлов: каталог сохраняет внутреннюю структуру как один
ресурс, а элементы массива можно независимо учитывать и обрабатывать. Звук,
изображение и документ не являются разными универсальными видами — это
артефакты с разными типами содержимого.

Внешний `uri` считается способом найти ресурс, а не новым видом содержимого.
Для версии 0.1 он отложен: сначала нужно определить загрузку, контрольную сумму,
авторизацию, сетевую политику и видимость ссылки.

## Пока не решено

- как обозначать необязательный вход в примере;
- когда порядок элементов набора значим;
- нужны ли производные, но открытые факты о входе;
- как упаковывать очень большие или чувствительные наборы данных;
- когда разрешить внешние URI и кто должен загружать их содержимое.
