# Спецификация задачи

Статус: черновик; основные границы согласованы.

## Назначение

Задача описывает общий класс требуемого результата независимо от конкретных
входных файлов и способа решения. Она не содержит команду `ffmpeg`, имя модели
или последовательность агентов.

## Минимальные поля

```yaml
schema_version: "0.1"
id: audio-to-mono-flac
version: "1"
title: Преобразование звука

intent: |
  Получить монофонический FLAC с частотой 16 кГц,
  сохранив длительность исходной записи.

inputs:
  - id: source_audio
    kind: artifact
    required: true
    media_types: [audio/wav, audio/flac, audio/mpeg]

outputs:
  - id: converted_audio
    kind: artifact
    required: true
    media_types: [audio/flac]

data_policy:
  external_transfer: forbidden

default_evaluation_policy: audio-conversion-v1
```

## Смысл полей

- `id` и `version` однозначно определяют версию задачи.
- `intent` сохраняет понятное человеку требование.
- `inputs` и `outputs` объявляют логические места, а не пути конкретных файлов.
- `media_types` ограничивает допустимые типы, не превращая бинарные данные в текст.
- `data_policy` описывает допустимое обращение с данными, а не техническую
  настройку сети конкретного запуска.
- `default_evaluation_policy` задаёт разумное оценивание по умолчанию.

Эксперимент может заменить правило по умолчанию или добавить другие правила.
Таким образом, оценивание можно исследовать независимо от постановки задачи.

## Пока не решено

- как описывать переменное количество выходных артефактов;
- входит ли политика данных в задачу или в отдельный переиспользуемый документ;
- как вычисляется версия: вручную, контрольной суммой или обоими способами.
